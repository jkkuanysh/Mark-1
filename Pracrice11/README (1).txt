Practice 11 - Pygame Projects

Files:
- racer.py
- snake.py
- paint.py

Run:
python racer.py
python snake.py
python paint.py

Requirements:
pip install pygame

Features:
1) Racer
- Random coins with different weights/values (1, 2, 3)
- Enemy speed increases when player earns N coins
- Commented code

2) Snake
- Random food with different weights/values
- Food disappears after some time using a timer
- Commented code

3) Paint
- Draw square
- Draw right triangle
- Draw equilateral triangle
- Draw rhombus
- Commented code

Notes:
- Paint controls:
  - Choose tool from toolbar
  - Choose color from palette
  - [ and ] change size
  - C clears canvas
