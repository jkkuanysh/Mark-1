Practice 10 - Pygame Projects

Files:
1. racer.py  - Racer game with coins and coin counter
2. snake.py  - Snake game with walls, food, levels, score, speed increase
3. paint.py  - Paint app with rectangle, circle, eraser, color selection

How to run:
Open terminal in this folder and run:
python racer.py
python snake.py
python paint.py

Requirements:
pip install pygame

Controls:
RACER:
- Left / Right arrows to move
- R to restart after losing

SNAKE:
- Arrow keys to move
- R to restart after losing

PAINT:
- Mouse to draw
- B = brush
- R = rectangle
- C = circle
- E = eraser
- + / - = change brush size
- SPACE = clear canvas
